# Lucid — Implementation Plan

## Phases

---

### Phase 1: Core Models + App Shell

**Goal:** Set up the project structure, SwiftData models, and the tab-based app shell.

```
Phase 1
├── 1.1  Create XcodeGen project.yml
├── 1.2  Create SwiftData models (Song, Playlist)
├── 1.3  Build MainTabView with 3 tabs (Songs, Playlists, Search)
├── 1.4  Wire up SwiftData ModelContainer
├── 1.5  Create empty state views per tab
└── 1.6  QA: App launches, tabs navigate, empty states show
```

---

### Phase 2: Import + Metadata Extraction

**Goal:** Enable importing MP3s from the Files app with ID3 metadata extraction.

```
Phase 2
├── 2.1  Build LibraryViewModel with import logic
├── 2.2  Implement UIDocumentPickerViewController wrapper
├── 2.3  Implement MetadataExtractor using AVAsset
├── 2.4  Copy MP3 files to Documents/Music/
├── 2.5  Wire "+" import button on Songs tab
├── 2.6  Show import progress indicator
└── 2.7  QA: Import 5 test MP3s, verify metadata + art extraction
```

---

### Phase 3: Audio Playback Engine

**Goal:** Full playback with background audio, lock screen controls, and shuffle/repeat.

```
Phase 3
├── 3.1  Build AudioPlayerService (AVFoundation wrapper)
├── 3.2  Configure AVAudioSession for background playback
├── 3.3  Implement MPNowPlayingInfoCenter integration
├── 3.4  Implement MPRemoteCommandCenter handlers
├── 3.5  Build PlayerViewModel (play, pause, next, prev, shuffle, repeat, seek)
├── 3.6  Expose PlayerViewModel as @Environment singleton
└── 3.7  QA: Background playback 3hrs, lock screen controls work
```

### Phase 4: Now Playing + Mini Player

**Goal:** Full-screen Now Playing UI and persistent Mini Player.

```
Phase 4
├── 4.1  Build NowPlayingView (full screen, swipe-to-dismiss)
├── 4.2  Build AlbumArtView with placeholder
├── 4.3  Build playback controls (prev, play/pause, next, shuffle, repeat)

├── 4.5  Build MiniPlayerView (64pt fixed bar)
├── 4.6  Tap mini player → expand Now Playing
├── 4.7  Hide mini player when nothing playing
└── 4.8  QA: Controls responsive, swipe dismiss works, art displays
```


## Milestone Order for Xcode Setup

1. **You (Mac):** Confirm XcodeGen is installed (`brew install xcodegen`)
2. **Me:** Generate `Lucid.xcodeproj` via XcodeGen
3. **Me:** Commit generated project to repo
4. **You:** Open in Xcode, run on simulator/device
5. **Me:** Build phases 1→8 locally in repo
6. **You:** Pull, build, test on real device
7. **Ship:** Tag release, you distribute via TestFlight
